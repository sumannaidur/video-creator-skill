# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct, which applies in full. In short:

- Be respectful and inclusive. Welcome people of every background and experience level.
- Give and accept constructive feedback. Focus on what is best for the project and its users.
- No harassment, insults, sexualised language or imagery, personal or political attacks, or publishing others' private information.

## Scope

All project spaces: issues, pull requests, discussions and reviews. It also applies when someone represents the project elsewhere.

## Reporting

Report unacceptable behaviour **privately** to the maintainer. For now, use GitHub's private reporting on this repository (see [SECURITY.md](SECURITY.md)) and mark the report "Code of Conduct". GitHub's "Report content" feature covers abusive content. Reports are handled confidentially.

The maintainer may remove, edit or reject contributions that violate this code, and may warn or ban participants. These are the enforcement guidelines of the Contributor Covenant 2.1.
