# TTS license and rights screening

Reviewed 2026-11-25; this is project screening, not a legal determination. Separate **code**, **weights**, **voice checkpoint/training lineage**, **reference audio**, **generated audio**, and **redistribution**. Freeze exact revisions and license texts before P005 downloads. A downloadable weight is not automatically cleared for commercial video publishing.

| Candidate | Code / weight evidence | Publishing and distribution gate |
| --- | --- | --- |
| [IndicF5](https://huggingface.co/ai4bharat/IndicF5) | Model card labels weights MIT; [code repo](https://github.com/AI4Bharat/IndicF5) license to verify at chosen revision. Gated model. | Card explicitly requires permission for cloned voices. Use only consensual, licensed reference speech and retain provenance. Generated-audio terms beyond card's cloning condition need final check. |
| [Indic Parler-TTS](https://huggingface.co/ai4bharat/indic-parler-tts) | Card labels Apache-2.0 weights; gated access; code dependencies may carry own terms. | Verify gate conditions and selected named speaker/voice rights before public use. Output-specific terms not separately identified in card review. |
| [Indic-TTS](https://github.com/AI4Bharat/Indic-TTS/blob/master/LICENSE.txt) | Repository code MIT; checkpoints are downloadable from [GitHub releases](https://github.com/AI4Bharat/Indic-TTS/releases), but a separate explicit weight/voice license was not established. | **Unresolved** commercial checkpoint and generated-audio rights; do not infer MIT code license covers weights. |
| [Indic-Speak](https://huggingface.co/bodhan-ai/indic-speak) | Weights under [Indic Open Model License v1](https://github.com/Bodhan-AI/bodhan-model-info/blob/main/licenses/indic-open-model-license/v1/Indic_Open_Model_License.md), not a standard permissive code license; upstream Llama-3.2-3B, SNAC, Vocos terms also apply. | License permits broad self-hosted commercial use but requires attribution when making model/derivative available and separate approval for certain third-party hosting; other scale/acceptable-use conditions need review. Generated speech/video rights are not expressly cleared by this summary. Do not treat this as a simple MIT model. |
| [MMS-TTS](https://huggingface.co/facebook/mms-tts) | Meta collection and per-language weights labeled CC-BY-NC-4.0. | Exclude from commercial publishing baseline; research-only use requires compliance with noncommercial/attribution terms. |
| [Piper](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/LICENSING.md) | Current engine GPL-3.0-or-later; original archived engine MIT. Voice weights have **separate** lineage-dependent rights. [Commercial-use list](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/COMMERCIAL_USE.md) identifies cleared training chains. | Review exact Hindi voice `MODEL_CARD` and ancestor datasets before use; code redistribution implications differ from merely generating audio. No blanket commercial license for all voices. |
| [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) | Official card labels Apache-2.0 weights and states commercial deployment is allowed; verify code and bundled voices at chosen revision. | Preserve applicable notices for redistributed components; no reference voice needed in baseline. Output-specific terms not identified. |
| [Chatterbox](https://huggingface.co/ResembleAI/chatterbox) | Official card labels MIT; inspect specific Hindi finetune card and code revision before install. | Reference audio is optional but must be authorized if used. Voice-cloning consent and likeness risks remain separate from model license. |
| [Vakyansh](https://github.com/Open-Speech-EkStep/vakyansh-tts) | Code MIT; specific checkpoint license and training-data chain not established. | Hold commercial use until checkpoint rights are documented. |
| [F5-TTS base](https://huggingface.co/SWivid/F5-TTS) | Code and official checkpoint have different terms; official weights CC-BY-NC-4.0. | Exclude base weights from commercial publishing; IndicF5 is a separate checkpoint with its own terms. |

For any voice-conditioned model, P005 must use a consented voice actor or a reference clip explicitly licensed for synthesis and publication; retain consent scope, source, transcript, and deletion policy. Never clone an identifiable person without authorization. If rights are ambiguous, stop before publishing or redistributing checkpoints. No model is approved as the final production engine by this review.
