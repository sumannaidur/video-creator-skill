# P033.1: Spatial layout foundation

Status: implementation pending local tests and visual evidence.

P032.4 demonstrated project-local candidate reuse but its drawbridge scenery remained mostly flat and repetitive. P031.4 had a useful topic-local projection helper. Generalize a small optional level one-point projection in the existing Paper kit: shared ground anchors, footprints and upright scale. Existing sky, haze, masonry, foliage and layered shadow helpers already cover material and environment treatments; do not duplicate them. This is not automatic environment generation, 3D or a scene template. No renderer contract changes, dependencies or external assets.

Validate the Node projection test, existing Paper kit regression and repository consistency. Next compare an unseen environment with meaningful near/mid/far placements, ground footprints, purposeful foreground and focal detail, using existing rendering and bounded keyframe review. No artistic or 8 GB compatibility claim until evidence exists.
