# P032.1: Shared source asset registry

Status: implementation on dev; focused local tests pending.

P031.5 demonstrated manual transfer and reusable wheel source, but artistic and physical mechanism review remain open. No benchmark assets are promoted. Start with a small stdlib registry for original JS source, immutable records and exact dependency pins, candidate and explicit review attestations, bounded metadata search and source retrieval. No renderer changes, database, media storage, downloads or new dependencies. A shared external directory supports native Claude/Codex; cross-host operation still needs validation. Cooperative lock and atomic publication protect ordinary concurrent writers; trusted local storage is not a sandbox. Search scans records until an index is justified. Automatic learning, project integration, cleanup and asset customization automation are deferred.

Run the focused test script and repository consistency check before P032.2; cross-project reuse of a reviewed source remains the next acceptance objective. See [source assets](../../skills/video-creator/references/source-assets.md).
