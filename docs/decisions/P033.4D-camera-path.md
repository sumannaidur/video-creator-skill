# P033.4D: Deterministic level camera trajectories

Status: implemented, local validation pending.

The locomotive benchmark demonstrated shared mechanical state; the lighthouse bridge viewpoint remained fixed. Reuse worldCamera and dynamic geometry rather than adding a renderer, dependencies or physics. A bounded key sequence interpolates world position, eye height and unwrapped yaw; an optional pure moving-target function computes horizontal bearing. Absolute time evaluation is independent of seek history. No automatic clipping, occlusion, pitch/roll, focus tracking in elevation or resource guarantee. Validate camera math, legacy world/rig tests, dynamic browser regression and repository checks. Actual integrated moving-camera footage is the next benchmark; artistic and production acceptance remain open.
