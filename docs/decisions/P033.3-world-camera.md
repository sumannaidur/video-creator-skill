# P033.3: Shared-world alternate camera views

Status: implementation pending local validation and visual evidence.

P033.1B/P033.2B station benchmarks used consistent world dimensions but only forward-facing cameras with translated origins. Add an optional level horizontal camera transform around groundPlane; preserve its existing interface and behavior. World-space shadows transform consistently. Explicit face projection and depth support author-controlled visibility and composition, not automatic 3D rendering. No renderer changes, new dependencies or external media.

Validate the Node world test, existing Paper kit regression and repository checks. Then demonstrate two genuinely different viewing directions of an original scene, shared geometry and light, correct visible faces, and independently authored movable components. Keep the benchmark bounded, no Full HD. Review actual frames; motion and publication acceptance remain separate.
