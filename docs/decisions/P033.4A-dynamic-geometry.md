# P033.4A: Deterministic time-dependent SVG geometry

Status: implementation pending local validation.

P033.3B used 200 beam slots per shot. Existing Paper renderAt already evaluates arbitrary-time transforms. Add opt-in dynamic SVG objects with fixed viewport and synchronous topic-authored draw(t) returning bounded markup. Update only the object's children when markup changes. Existing symbol objects and renderer API remain unchanged. Pure time-derived geometry is a topic responsibility, not enforced purity; no sandbox. No dependencies or external media. Per-frame computation and DOM replacement cost must be measured. No automatic camera motion, hierarchy, physics or internal SVG bounds checks.

Validate browser test for changing pixels, backwards seek and shot rebuild, invalid viewport/output, existing Paper kit regression and repository checks. Compare actual motion and resource use before accepting production use.
