# P028.2: One world, three framings

An opt-in original Paper Explainer artwork benchmark; not a reusable topic template and not an artistic acceptance result.

Run from the repository root:

```powershell
node skills/video-creator/scripts/tests/cinematic_chai.mjs
```

Optional first argument: an external output directory. Default: system temporary directory / vc-chai-benchmark. The test uses synthetic phrase timing, no speech generation, downloads or video encoding. It captures three portrait keyframes, checks repeatability and inspects 360 frame times. Review the actual PNGs at phone size for coherent lighting, identifiable objects, depth, continuity and compelling framing. Zoom is not a different viewpoint. Report intentional crops separately from unintended gaps. Character interaction and audio are deliberately deferred. No engine changes.
