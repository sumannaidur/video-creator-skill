### Measured synthesis results

The resumed voice transfer completed first. The model transfer stopped on curl exit 6 with HTTP 000 for chunk 272. A four-worker continuation reused the retained chunks and filled the remaining 31 ranges. Both final assets matched the exact sizes and published SHA-256 hashes in the model manifest. Together they contain 353,719,767 bytes. The measured external experiment footprint, including the existing venv, cache, assets and logs, was 603,889,089 logical bytes. Workspace free space before synthesis was 133.70 GiB. Actual total wire bytes, including retries, were not captured.

Both passages ran with the local CPU provider, four intra-op threads, one inter-op thread, graph optimization and prepacking disabled to reduce memory risk, and no trimming. The runner used absolute local model paths, process-scoped offline settings and a Python socket audit guard. Both runs succeeded without a fetch. This check did not isolate native code from the network at the OS level.
