## Dependency path and sequencing

The shortest practical R01 path is `P01.1 → P01.2 (retention/failure slice) + P02.1/2 → P03.1/2 → P13.1 (one locale) + P04.1 → P05.1 (one voice) + P13.2 (one locale) + P05.2 → P04.2 + P06.1/2 → P07.1/2 → P08.1/2 → P09.1 (one script) + P09.2 + P10.1/2 → P11.1/2 → P12.1 → P12.2 (human review)`. E02, E03, E05, E06, E07, and E08 run early enough to reject unsuitable routes. The one-language R01 route needs its own quality evidence. E01 establishes the portable contract but runtime validation remains open. E09 checks the timeline. E10 integrates the path.

For R01, implement the minimum validated slice of P05.1 (licensed local voice plus actual listening), P09.1 (correct script shaping, wrapping, and readability), P13.1 (native conversational guidance), and P13.2 (numbers, names, terms, pronunciation) for the chosen sample locale. The row's R02 label marks completion across all five locales. P12.2 has an R01 single-locale gate: actual narration, story, visual quality, animation, and final video receive human review. The complete R02 gate repeats the language-specific and human evaluations independently in all five locales. The R01 dependency path includes these minimum slices before dependent work. R03 adds independently tested styles and selector; R04 adds research integration, batches, cache, and partial regeneration; R05 packages only verified host variants. Broad items P05.2, P07.1/2, P08.1/2, P09.1/2, P11.1/2, P12.1/2, and P13.1/2 need finer task breakdown before implementation; later-release features need their own atomic breakdown then.
